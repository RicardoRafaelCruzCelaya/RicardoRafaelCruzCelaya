## The problem I want to help solve

**End-to-end artifact automation with verifiable fidelity to user intent.**

An AI assistant may correctly discuss requirements and generate individual components, yet still fail to deliver a finished artifact that preserves approved decisions, visual layout, editability, and export requirements.

My reference case involves developing a **20-page illustrated educational guide** through an extended AI-assisted workflow. The recurring difficulty was not merely producing text or individual pages; it was maintaining visual consistency, applying targeted corrections without unintended changes, and delivering a complete, editable final document.

I am interested in evaluating this class of problem through reproducible tasks and explicit acceptance criteria, including:

- **Requirement preservation:** approved instructions and previous decisions remain in force.
- **Visual fidelity:** edits preserve unaffected elements and page geometry.
- **Completion:** the complete deliverable is produced in the requested formats.
- **Editability:** the source file is meaningfully editable, not merely a flat image inside a document.
- **Repair burden:** the amount of manual intervention required from the user is measured.
- **Evidence:** successes, failures, and limitations are documented rather than inferred.
